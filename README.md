# End-to-End-diwali-sales-dashboard
🚀 Project Workflow

1. Collected the raw Diwali Sales dataset.
2. Cleaned and preprocessed the data using Python (Pandas).
3. Imported the cleaned data into MySQL.
4. Connected Power BI to the MySQL database.
5. Created interactive dashboards and KPIs.
6. Analyzed customer behavior and sales trends.
